# ruby66
66 key split ergo keyboard, based on the lily58 and redox

# design considerations
- same key stagger layout as the lily58
- angled thumb button placed under the 5/6 columns a la redox
- bottom row extended back towards the pinky corner

# building
design can be built from scratch using the ergogen config file. the pcb uses [ceoloide's footprints](https://github.com/ceoloide/ergogen-footprints).

provided gerber files can be used to purchase the PCB from your manufacturer of choice
